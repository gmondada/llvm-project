# LLDB DAP Android

This experimental version of the LLDB DAP extension enables debugging of Android apps with a smooth and intuitive user experience. It is part of a broader effort to enable Swift debugging on Android, but is not limited to Swift.

Project related informations:
* https://discourse.llvm.org/t/rfc-android-support-in-lldb-dap-vs-code-extension/89903
